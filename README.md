# Coin-Flipping

A simple and interactive coin-flipping web application built with React, Vite, and Tailwind CSS.

## Features

- 🪙 Flip a coin and get random results (Heads or Tails)
- ⚡ Lightning-fast performance powered by Vite
- 🎨 Beautiful UI with Tailwind CSS
- 📱 Responsive design

## Tech Stack

- **React** 19.2.3 - UI library
- **Vite** 7.3.2 - Build tool and dev server
- **Tailwind CSS** 4.1.17 - Utility-first CSS framework
- **TypeScript** 5.9.3 - Type safety

## Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd Coin-Flipping
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:5173`

## Available Scripts

- `npm run dev` - Start the development server
- `npm run build` - Build the application for production
- `npm run preview` - Preview the production build locally
